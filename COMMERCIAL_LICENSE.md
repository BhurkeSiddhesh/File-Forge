## Why Dual-Licensing?

The AGPLv3 is a strong copyleft open-source license. It allows anyone to use, modify, and distribute the software for free, **provided** that any modifications or applications built upon it are also released as open-source under the AGPLv3. This ensures that the open-source community benefits from improvements.

However, many businesses require the ability to use File Forge in commercial, proprietary, or closed-source environments where they cannot or do not wish to share their source code under the AGPLv3.

For these use cases, we offer a Commercial License.

## When do you need a Commercial License?

You **need** a Commercial License if you intend to:

1. Integrate File Forge into a commercial, closed-source product or service.
2. Provide File Forge as a Software-as-a-Service (SaaS) where you do not want to publish your backend source code.
3. Modify the software without sharing your modifications publicly.
4. Distribute the software as part of a proprietary bundle.

You **do not need** a Commercial License if you:

1. Are building an open-source project licensed under AGPLv3.
2. Are using the software for personal, academic, or non-commercial testing purposes without distributing it or offering it as a public network service.
